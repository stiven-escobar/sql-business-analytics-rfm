# 🗄️ SQL Business Analytics & Customer Segmentation (RFM)

Modelado de base de datos relacional y consultas analíticas avanzadas en **SQL (SQL Server / PostgreSQL)** orientadas a inteligencia comercial, control de cartera y segmentación de clientes (RFM).

## 🛠️ Competencias SQL Demostradas
* **DDL & Modelado Relacional:** Creación de tablas normalizadas, llaves primarias/foráneas e integridad referencial.
* **Consultas Analíticas Avanzadas:** `JOINs` complejos, `CTEs` (Common Table Expressions), subconsultas y `Window Functions` (`RANK()`, `LAG()`, `SUM() OVER()`).
* **Lógica de Negocio:** Cálculo de Recencia, Frecuencia y Valor Monetario (RFM), retención de clientes y análisis de márgenes operativos.
